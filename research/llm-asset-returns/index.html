Language models and asset-return signals

An investigation into whether information extracted from text can become a measurable, testable financial-market signal.

StatusOngoing
RoleResearch
Date2026
OutputProject notes

The question

Text contains information that conventional numeric datasets can miss. The core question is not simply whether a model can summarize that text, but whether a precisely defined output contains incremental information about later returns after realistic controls.

Why it matters

Language models make rich documents easier to structure at scale, but flexibility creates room for hidden researcher discretion. A useful result must survive careful timestamping, out-of-sample evaluation, and transaction-cost assumptions.

Method

The conceptual pipeline separates document collection, signal construction, portfolio formation, and evaluation. That separation makes it easier to locate leakage and compare a text-derived signal with simple baselines.

future return = alpha + beta × text signal + controls + error

Results and limitations

Work in progress. Numerical findings and publishable artifacts are intentionally withheld until the analysis is complete and can be documented with appropriate context.

Key risks include look-ahead bias, instability across market regimes, prompt sensitivity, multiple testing, and the gap between statistical and economic significance.
